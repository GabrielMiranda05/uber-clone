# Uber Clone

Clone de app de transporte por aplicativo, com back-end próprio em **Java + Spring Boot**
e app **Android nativo** em Kotlin + Jetpack Compose.

> 🚧 Em desenvolvimento. O roadmap completo será documentado aqui.

## Estrutura

- `backend/`: API REST + WebSocket (Spring Boot)
- `android/`: app nativo (Kotlin, Compose)
- `docs/`: documentação e decisões de arquitetura
